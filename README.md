# ONLINE PvP FIGHT — Arena Zero (Multiplayer)

مشروع لعبة قتال متصفح 1 ضد 1 مبني على HTML/CSS/JavaScript مع Node.js وSocket.IO. تم الإبقاء على نسخة التدريب ضد الكمبيوتر، وإضافة غرف خاصة ومطابقة عشوائية واتصال لحظي بين لاعبين.

## محتويات ZIP
- `public/index.html` — الواجهات والقائمة واللوبي.
- `public/style.css` — التصميم المتجاوب.
- `public/game.js` — محرك الرسم والقتال الأصلي، التدريب ضد CPU، وعرض حالة المباراة الشبكية.
- `public/online.js` — واجهة Socket.IO: إنشاء الغرفة، الانضمام بالكود، البحث العشوائي، الترتيب.
- `server.js` — خادم Node.js، إدارة الغرف، المطابقة العشوائية، محاكاة القتال والتحقق من الضرر، الترتيب.
- `package.json` — الاعتماديات وأوامر التشغيل.
- `render.yaml` — إعداد نشر Render.
- `.env.example`, `.gitignore`.

## التشغيل محلياً
1. ثبّت Node.js 18 أو أحدث: https://nodejs.org/
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   ```bash
   npm install
   npm start
   ```
4. افتح `http://localhost:3000`.
5. لاختبار لاعبين محلياً افتح الرابط في نافذتين أو جهازين على نفس الشبكة (استخدم IP الكمبيوتر بدلاً من localhost للجهاز الثاني).

## النشر على Render
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. في Render اختر **New + → Blueprint** واربط المستودع؛ سيقرأ `render.yaml`.
   - أو أنشئ Web Service يدوياً: Runtime Node، Build Command `npm install`، Start Command `npm start`.
3. بعد النشر افتح رابط `https://اسم-الخدمة.onrender.com`.
4. اللعبة والـ Socket.IO server مستضافان على نفس الخدمة، لذلك لا تحتاج إلى وضع رابط سيرفر منفصل في الواجهة.
5. Render Free قد يوقف الخدمة بعد فترة خمول؛ أول اتصال بعد الخمول قد يتأخر. تحقق من خطط Render الحالية وحدودها قبل إطلاق عام.

## طريقة اللعب
- **تدرب ضد الكمبيوتر:** يحتفظ بالنسخة الأصلية.
- **غرفة خاصة:** أنشئ غرفة، شارك الرمز المكوّن من 6 أحرف/أرقام، والطرف الآخر يدخل الرمز.
- **مباراة عشوائية:** يدخل اللاعب طابور المطابقة، ويُقرن بأول لاعب ينتظر.
- **الترتيب:** نقاط RP وفوز وخسارة؛ يبدأ اللاعب من 1000 RP.

## التحكم
A/D أو الأسهم للحركة، W للقفز، S للدفاع، J لكمة، K ركلة، L ضربة خاصة، Shift اندفاع، Esc إيقاف مؤقت.

## حدود النسخة الحالية — اقرأ قبل النشر العام
- هذه نسخة Multiplayer أولية عملية وليست منتجاً تنافسياً جاهزاً للإطلاق التجاري.
- نظام الرتب والنتائج محفوظ في ذاكرة السيرفر فقط؛ يعاد ضبطه عند إعادة تشغيل الخدمة أو إيقافها. لإنتاج فعلي أضف PostgreSQL أو Redis وقاعدة بيانات لحسابات اللاعبين.
- لا توجد حسابات مستخدمين أو تحقق هوية أو نظام بلاغات/حظر.
- محاكاة الخادم هي المرجع للصحة والضرر، لكن الحركة/الاصطدامات ما زالت مبسطة، ويجب اختبارها وضبطها مع زمن الشبكة والـ latency.
- لا يوجد نظام تعويض تأخير (lag compensation)، rollback netcode أو إعادة اتصال إلى نفس المباراة.
- واجهة اختيار اسم اللاعب غير مضافة بعد؛ تُستخدم أسماء مؤقتة من معرف اتصال Socket.IO.
- تأكد من إضافة حدود معدل للأحداث، والتحقق من Origin، ومراقبة السجلات، وحماية من الإساءة قبل فتح السيرفر للجمهور.
- يتم تحميل Socket.IO client من نفس الخادم، والخطوط من Google Fonts عند توفر الإنترنت.

## اقتراحات ما قبل الإطلاق
إضافة قاعدة بيانات دائمة، حسابات آمنة، ملف لاعب، اختيار شخصيات، نظام أفضل من 3 جولات، إعادة مباراة، إعادة اتصال، مكافحة غش أقوى، لوحة إدارة، واختبارات ضغط لعدد الغرف المتزامنة.
